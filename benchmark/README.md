# Бенчмарки

- `mandl/` — Mandl, 15 остановок; загрузка: `tndp.load_mandl()`.
- `mumford0/` — Mumford 0, 30 остановок; загрузка: `tndp.load_mumford0()`.
- `kemerovo/` — Кемерово, 344 узла; матрицы и сохранённые геометрии дорог, загрузка: `tndp.load_kemerovo()`.

Координаты, времена проезда и OD-спрос хранятся отдельно. Времена проезда заданы
в минутах, `Inf` обозначает отсутствие уличной связи. Пути загрузчиков по умолчанию
заданы относительно корня проекта. Источник Mandl указан в `mandl/README.md`.
Mumford 0 взят из набора `datasets/instances/mumford0` проекта ConnectPT.
Исходные данные входят в Git. В Кемерове координаты файлов заданы в метрах
EPSG:32645, времена — в минутах. Загрузчик переводит координаты в километры
и сохраняет направленный спрос. Полилинии дорожных рёбер находятся в
`kemerovo_simplified_graph.pkl`; они используются для переноса предсказанных маршрутов.
