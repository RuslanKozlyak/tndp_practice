# Mandl

The 15-stop Mandl example is loaded by `tndp.load_mandl()`.

- `MandlCoords.txt`: node count, followed by coordinates.
- `MandlTravelTimes.txt`: street times in minutes; `Inf` means no edge.
- `MandlDemand.txt`: OD trip counts.

Benchmark collection: https://users.cs.cf.ac.uk/C.L.Mumford/Research%20Topics/UTRP/CEC2013Supp.zip
