# Проектирование маршрутной сети

Учебный проект по проектированию маршрутных сетей общественного транспорта с помощью ИИ.
В ноутбуке сравниваются RL, LC, EA и NEA, меняется функция стоимости и строятся маршруты
на тестовых графах и для города Кемерово.

## Локально

В терминале выполните:

```powershell
git clone https://github.com/RuslanKozlyak/tndp_practice.git
# Клонирование репозитория.

cd tndp_practice
# Переход в папку проекта.

python -m venv .venv
# Создание отдельного окружения проекта.

.\.venv\Scripts\python.exe -m pip install -e .
# Установка проекта и его зависимостей.
```

Откройте `tndp_experiments.ipynb`, выберите ядро `.venv` и выполняйте ячейки сверху вниз.

## Google Colab

1. Откройте [ноутбук в Colab](https://colab.research.google.com/github/RuslanKozlyak/tndp_practice/blob/main/tndp_experiments.ipynb).
2. В первой кодовой ячейке раскомментируйте блок для Google Colab: он клонирует репозиторий,
   устанавливает проект и включает интерактивные виджеты.
3. Выполняйте ячейки сверху вниз.
